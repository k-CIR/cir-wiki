This section covers the main software tools used for MEG data analysis and file management at NatMEG.

## Pages in this section

- [SESHAT](./seshat.md) - the NatMEG preprocessing pipeline for SQUID and OPM data.
- [MaxFilter](./maxfilter.md) - background and links for MaxFilter-based preprocessing.
- [BIDS](./bids.md) - NatMEG-specific BIDS conversion notes.
- [MNE-Python](./mne-python.md) - open-source Python package for MEG/EEG analysis.
- [FieldTrip](./fieldtrip.md) - open-source MATLAB toolbox for MEG/EEG analysis.
- [Presentation](../presentation/index.md) - stimulus delivery software used at NatMEG.
- [Beyond Compare](./beyond-compare.md) - file manager and FTP client for transferring data to Archive.
